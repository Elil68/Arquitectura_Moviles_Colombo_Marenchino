# TP2 Mis Tareas Académicas

Aplicación móvil nativa desarrollada para el Trabajo Práctico 2 de Arquitecturas Móviles.

El proyecto consiste en un MVP para la organización de tareas académicas personales. Fue desarrollado en Kotlin con Jetpack Compose y utiliza Firebase para la autenticación de usuarios y el almacenamiento de la información.

## Tecnologías

- Android Studio
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
