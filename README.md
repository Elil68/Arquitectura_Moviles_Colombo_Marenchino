# TP1 - Aplicación Hola Mundo

Aplicación Android nativa desarrollada en Kotlin utilizando Jetpack Compose.

## Funcionalidades

- Muestra el mensaje “Hola Mundo”.
- Permite navegar a una segunda pantalla.
- Utiliza un `Intent` para realizar la navegación.
- Permite regresar a la pantalla principal.
- Registra eventos del ciclo de vida de `MainActivity`.

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Jetpack Compose
- Material 3
